# 拉片卡 · 场景学习工作台

一个本地优先的电影拉片工具。它按影片项目管理场次，帮助使用“谁—要—做—阻—变—知”拆解人物行动，并生成适合发布的竖版学习卡。

## 核心功能

- 按影片项目管理场次，场号自动递增
- 每场保留一张主截图，最多增加到三张；支持排序和调整构图焦点
- 每场可增加一至三条人物行动线
- 自动生成两张基础卡；“我的发现”第三张按需开启
- 拉完全片后统一补充幕与节拍位置
- 使用浏览器本地数据库自动保存文字与截图
- 单场导出 Markdown；整片导出 Obsidian 文件夹、截图和恢复备份
- 完整数据可以随时备份和恢复

## 数据与隐私

影片笔记和截图只保存在使用者当前浏览器的本地数据库中，不会上传到 GitHub。清理浏览器网站数据前，请先点击“备份数据”。

## 使用

打开网站后新建影片项目即可使用。推荐流程：

1. 第二遍观看时逐场记录。
2. 每场先完成两张基础卡，有实际收获时再开启第三张。
3. 拉完整部电影后进入“全片复盘”，统一补幕和节拍。
4. 一键导出整部影片，解压后放进 Obsidian 库。

## 项目结构

- `index.html`：页面结构
- `styles.css`：固定视觉系统
- `app.js`：项目管理、本地存储、卡片生成与导出

本项目不依赖账号、服务器或构建工具。
